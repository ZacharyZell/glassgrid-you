Compared to v1.2.0: Introduces opt-in AI Agent control (28 MCP tools, glassgrid CLI, 12 Siri App Intents), expands the hub to 18 services with Crunchyroll and hardened Prime Video sign-in, renders video Clean-Box across all services, and floats full 2–4 stream Multiview Grids.

0 → 28 MCP Tools & 12 Siri Intents 17 → 18 Services (+Crunchyroll) Single → Floating Multiview Grid +Universal Clean-Box (⌘⇧B)
Added
  • AI Agent, Local MCP Server & glassgrid CLI: Bundled stdio MCP server and standalone CLI (zero AppKit/WebKit/Sparkle linkage) exposing 28 tools and 5 read-only resources (MCP 2025-06-18 / 2025-03-26 / 2024-11-05), with 1-click config installation for Claude Desktop, Claude Code, Gemini CLI, Antigravity, and Grok CLI plus opt-in local Streamable HTTP MCP (127.0.0.1:41773/mcp).
  • Siri, Apple Intelligence & Shortcuts: Added 12 native App Intents and 8 App Shortcuts (Play/Pause, Now Playing, Search YouTube, Open Service, Launch Multiview Preset, Toggle Mini-Player, Focus Mode, Sleep Timer) extracted into Metadata.appintents, plus opt-in glassgridyou://action/... URL triggers.
  • Universal Clean-Box Service Rendering (⌘⇧B): Automatically isolates only the active video player container edge-to-edge across all 18 built-in streaming services (including cross-origin player iframes like Crunchyroll and overlay SDK players like Prime Video & Apple TV+), while keeping home, browse, guide, and login pages untouched. Toggle anytime with ⌘⇧B or the header pill for Full Page.
  • Floating Multiview Grid Mini-Player (⌘⇧M): Float an entire 2-up, 3-up, or 2×2 Quad-Box grid into the always-on-top borderless 16:9 panel with zero reload, crimson active-audio borders, click-any-tile audio focus, compact 44pt hover header, Display Options popover (40%–100% opacity, Grid/Spotlight/Stacked layouts, Play/Pause All), and Grid size presets (Compact 540×304, Standard 680×383, Large 880×495; minimum 440×248).
  • Crunchyroll in Streaming Hub: Added Crunchyroll to Movies & Shows (growing the catalog from 17 → 18 services: 11 native WKWebView + 7 Safari-DRM-badged) with native OAuth popup isolation and Safari DRM fallback.
Changed
  • New Settings → AI & Automation Tab: Added master opt-in toggle, 3 permission tiers, socket/HTTP live status indicators, Bearer token mask/reveal/rotate controls, and a 100-entry live Activity Log.
  • Split Screen–Aware Auto Pop-Out for Multiview: Leaving or covering the app while a Multiview stream is playing now floats the entire Multiview Grid instead of detaching only a single video, and docks cleanly when switching back.
Fixed
  • Prime Video & Crunchyroll Login Reliability: Hardened sign-in across 18 regional Amazon storefronts with direct OpenID routing, locale-segment stripping (/es-es/login, /pt-br/login), non-destructive session cookie presence checks, and immediate Clean-Box script teardown on auth, OAuth, MFA, or CAPTCHA pages.
  • Connected Streaming Services, SPA Auth & App-Handoff Hardening: Updated HBO Max (play.hbomax.com / hbomax.com/auth/*), fixed Disney+ /identity/login & MyDisney SSO isolation, prevented false-positive sign-in completion on YouTube TV (/welcome) and Apple TV+, added lazy post-auth SPA script bootstrapping & Sign-In Hub URL KVO, blocked streaming app-handoff URI schemes, and added natural service aliases (hbomax, disney+, appletv+) + MCP discovery completeness across CLI/Siri/MCP clients.
  • Crunchyroll Dual-Path Clean-Box & Wrapper Fill Hardening: Added dual-path resolution across Crunchyroll Vilos player iframes and modern Katamari inline HTML5 players (with direct no-clobber iframe promotion, intermediate aspect-ratio wrapper neutralization via data-ytmac-cb="chain", 4-step SPA settle retries, lazy subframe sizing, and modal-dismiss recovery) so Crunchyroll fills Multiview, Single View, and Mini-Player boxes edge-to-edge while preserving controls and tall-tile letterboxing.
  • YouTube Live Chat Overlap in Tiles & Floating Overlay Alignment: Suppressed narrow-viewport live chat drawers (#panels-full-bleed-container, ytd-live-chat-frame) inside compact Multiview tiles and stripped titlebar safe-area insets from floating grid borders for 0pt pixel alignment.
Security & Privacy
  • Fail-Closed Local Automation Defaults: AI Agent control, HTTP MCP, and URL triggers ship strictly OFF by default. Stdio CLI IPC uses owner-only UNIX domain sockets (0600 in 0700, getpeereid EUID check, zero tokens in config files); optional HTTP binds strictly to 127.0.0.1 with Host/Origin/256-bit Bearer token (0600 in Application Support) + 60 req/min rate limiting; cookies, SSO logins, arbitrary JS, and site-data wipes are permanently blocked.

WebKit Invariants: Zero CSS :has(, zero MutationObserver, zero AudioContext, zero static ytInitialPlayerResponse; Swift 6 strict concurrency (0 warnings Debug & Release); 77 unit tests passing (including offline WKWebView Clean-Box & SPA auth-exit DOM geometry fixtures, 18-service matrix, MCP discovery & security verification).
